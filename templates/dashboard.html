API Integration Guide
  • Create Order
  • Check Status
  • Webhook Payload
POST {{ request.host_url.rstrip('/') }}/api/create-order

Initiates a payment order and returns a secure payment URL to redirect your customer.

REQUEST HEADERS
X-Fam-Key: {{ user_info.api_key if user_info else 'YOUR_API_KEY' }}
Content-Type: application/json
JSON REQUEST BODY
{
    "amount": "100.00",
    "order_id": "ORD12345",
    "customer_name": "Raushan Kumar",
    "callback_url": "{{ request.host_url.rstrip('/') }}/callback"
}
RESPONSE BODY
{
    "status": "success",
    "payment_url": "{{ request.host_url.rstrip('/') }}/pay/LRd7jTF0V2sFyhMyOBzbJLL1S"
}
GET {{ request.host_url.rstrip('/') }}/api/verify?api_key={{ user_info.api_key if user_info else 'YOUR_API_KEY' }}&txn_id=FAM172...

Check the status of a specific transaction ID programmatically.

RESPONSE BODY
{
    "status": "completed",
    "data": {
        "amount": 100.0,
        "paid_at": "2026-08-27T10:15:30",
        "txn_id": "FAM1723...",
        "utr": "412345678901"
    }
}

When a payment is successfully verified, we will instantly send a POST request containing the transaction details to the callback_url you provided during Order Creation.

WEBHOOK POST BODY
{
    "amount": 100.0,
    "merchant_order_id": "ORD12345",
    "status": "success",
    "txn_id": "FAM1723...",
    "utr": "412345678901"
}

Tip: Always verify the payment amount and order ID on your end before fulfilling the order.
